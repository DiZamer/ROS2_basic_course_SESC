# 2_homework/

## Назначение папки

Здесь лежат домашние задания к каждому занятию курса «Основы продвинутой робототехники».

Каждое задание — один шаг к собственной виртуальной модели робота: пакет, узел, сенсор, управление, навигация или манипуляция. К концу курса студент собирает собственного робота из этих шагов.

Домашние задания выполняются дома в devcontainer, без преподавателя и без оборудования компьютерного класса.

## Соглашение об именах

Имя файла: `hw_NN_<тема>.md`, где `NN` — номер занятия (двузначный, `01`–`30`).

Примеры:

- `hw_09_topic.md` — ДЗ к занятию 9 «Topic, publisher, subscriber»;
- `hw_17_urdf.md` — ДЗ к занятию 17 «Simulation-first: URDF/rviz2».

Знания (`2_knowledge/`) остаются тематическими, без номера. Нумеруются только практики (`2_practice/NN_*.md`), демонстрации (`1_demo/demo_NN_*.md`) и домашние задания (`2_homework/hw_NN_*.md`).

## Правила домашних заданий

- Выполняется дома в devcontainer: ROS2 Jazzy для уровня 2, TIAGo в ROS2 Humble для уровня 3. ROS2 не устанавливается на хост.
- Одно задание на одно занятие.
- Задание ссылается на материалы занятия: лекцию, практику и кейс робота.
- В задании есть критерии готовности — по каким признакам оно считается выполненным.
- Задание ведёт к виртуальной модели робота: явно указан элемент модели, который добавляет студент.
- Задание рассчитано на самостоятельное выполнение между занятиями.

Структура одного задания — раздел «Шаблон домашнего задания» в [`CONTENT_TEMPLATES.md`](../CONTENT_TEMPLATES.md).
