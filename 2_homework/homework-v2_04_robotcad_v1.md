# Домашняя работа-v2 04: модель мобильной базы в RobotCAD

## Цель

Создать и сохранить простую модель собственной платформы в FreeCAD/RobotCAD, экспортировать URDF/Xacro и задокументировать структуру links, joints и LCS.

## Связь с занятием

На занятии студент превратил CAD-геометрию в структурную модель робота. Дома он адаптирует модель к выбранному сценарию, сохраняя проект для последующего добавления сенсоров и симуляции.

## Предварительные требования

- Выполнена домашняя работа 2: есть папка `~/my_robot/` и краткая идея робота.
- Выполнена домашняя работа 3 либо создан дневник проекта.
- Установлены FreeCAD и RobotCAD по подготовленной преподавателем инструкции; ROS 2 на хост не устанавливается.
- Прочитаны [`robotcad.md`](../2_knowledge/robotcad.md) и материал занятия 4.

Если GUI/RobotCAD недоступны, выполните план Б и согласуйте экспортированную модель с преподавателем; не устанавливайте ROS 2 на хост.

## Шаг к виртуальной модели

Это первый геометрический элемент собственной модели. В занятиях 17–18 он станет входом для URDF/Xacro и симуляции.

## Шаг 1. Создать геометрию своего корпуса и колёс

Создайте проект FreeCAD `~/my_robot/mobile_base.FCStd`. Сделайте:

- корпус платформы;
- два колеса (или колёсный модуль, если выбран другой тип базы);
- осмысленное расположение относительно корпуса.

Для размеров запишите допущения: ориентировочная длина/ширина базы и радиус колеса. Это учебные параметры, которые можно будет менять.

## Шаг 2. Назначить структуру

В RobotCAD создайте links для корпуса и подвижных частей. Для дифференциальной базы ожидаются имена:

- `base_link`;
- `wheel_left_link`;
- `wheel_right_link`.

Создайте два вращательных joints с согласованными parent/child. Проверьте оси и точки сочленений через LCS/placement-инструменты.

## Шаг 3. Проверить физические свойства

Назначьте материалы или массы доступными в текущей версии RobotCAD средствами. Пересчитайте массу/инерцию и запишите:

- какие материалы были заданы;
- какие единицы использовались;
- какие параметры требуют будущей проверки по реальному роботу.

## Шаг 4. Экспортировать URDF/Xacro

Сохраните исходный `.FCStd` и сгенерированные файлы отдельно:

```text
~/my_robot/
├── mobile_base.FCStd
├── robotcad_export/
│   ├── urdf/       # расположение зависит от настроек генератора
│   └── meshes/     # если генератор создаёт отдельные меши
└── diary.md
```

Не создавайте вручную пакет ROS 2 на этом занятии. Используйте экспорт RobotCAD; package/build integration будет изучаться позже.

## Шаг 5. Записать результат в дневник

Добавьте в `~/my_robot/diary.md`:

```markdown

- Base link:
- Wheel links:
- Joint names and types:
- Axis of rotation:
- Approximate dimensions:
- Mass/material assumptions:
- Files exported:
- One item to verify before simulation:
```

## План Б: разобрать готовое описание

Если GUI недоступен, используйте предоставленный преподавателем экспорт и:

1. перечислите links;
2. сопоставьте каждому joint parent и child;
3. укажите ось вращения колеса;
4. найдите visual/collision/inertial и mesh paths;
5. опишите, какую информацию нельзя восстановить по одному URDF-фрагменту без исходной CAD-модели.

## Ожидаемый результат

- Сохранён исходный FreeCAD-проект.
- Есть экспортированное описание с корпусом, колёсами и сочленениями.
- Имена links/joints и оси описаны в дневнике.
- Записано хотя бы одно инженерное допущение или параметр для последующей проверки.

## Вопросы для самопроверки

1. Чем исходная CAD-геометрия отличается от URDF?
2. Как LCS влияет на placement joint?
3. Какие причины могут сделать автоматически рассчитанную массу неверной?
4. Зачем сохранять и `.FCStd`, и экспортированные URDF/Xacro/meshes?

## Критерии выполнения

- Есть `.FCStd` либо заполнен план Б.
- Модель содержит понятную структуру links/joints.
- Экспорт открывается как текст и содержит согласованные имена.
- Дневник описывает параметры и допущения.
- ROS 2 не устанавливался на хост.

## Типичные ошибки

| Ошибка | Исправление |
| --- | --- |
| Отправлен только скриншот | Сохранить исходный проект и экспорт, чтобы его можно было проверить. |
| Нет отдельных wheel links | Создать отдельный link для каждой подвижной части. |
| Имена разные в CAD и URDF | Сверить дерево RobotCAD с результатом генерации. |
| Масса считается точной без проверки | Записать материал/единицы как допущение и перепроверить позже. |
