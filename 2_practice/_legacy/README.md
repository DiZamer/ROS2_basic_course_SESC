# _legacy: практики прежнего курса

Материалы двухчасовой лекции (прежний формат, практики `01`-`08` по порядку). Оставлены как источник для переписывания под годовой курс.

Почему лежат здесь: в новом курсе число в имени файла — это номер занятия (01-30), а не сквозной номер практики. Старые имена конфликтовали с новыми (например, `05_action.md` и `05_sensors.md`).

Соответствие старых файлов новым занятиям:

| Старый файл | Тема | Новое занятие | Новый файл |
| --- | --- | --- | --- |
| `01_workspace.md` | Workspace, package, `colcon` | 7 | `07_workspace.md` |
| `02_package.md` | Node, Executor, callbacks | 8 | `08_node.md` |
| `03_topic.md` | Topic, publisher, subscriber | 9 | `09_topic.md` |
| `04_service.md` | Service и client | 10 | `10_service.md` |
| `05_action.md` | Action server и client | 11 | `11_action.md` |
| `06_launch.md` | Parameters и launch | 14 | `14_parameters_launch.md` |
| `07_tf2.md` | tf2 и дерево координат | 15 | `15_tf2.md` |
| `08_mini_project.md` | Мини-проект | 23 | `23_mini_project.md` |

Новые файлы создаются по этапам; после переноса содержания старые файлы удаляются. Удалить эту папку можно, когда все занятия 7-23 будут переписаны.

Соглашения об именах — [`../../CONTENT_TEMPLATES.md`](../../CONTENT_TEMPLATES.md), раздел «Соглашения об именах файлов».
